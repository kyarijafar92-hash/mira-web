# sec-suite-extras

Extra utilities, lab environment, and report/ticket templates to support authorized security testing in a controlled lab.

What’s included
- report_merge.py — merges per-tool JSON outputs into a single normalized report and renders a colored HTML report.
- templates/ticket_templates.md — GitHub Issue and Jira templates for filing findings.
- docker/ — docker-compose lab (OWASP Juice Shop + DVWA) and instructions to run a safe test environment locally.
- install_guides.md — step-by-step, safe installation and usage guides for common security tools (Metasploit, Pocsuite3, XSStrike, GoPhish, Locust, Wapiti, Sublist3r).
- run_demo.sh — example script that brings up the lab and shows example safe scanner commands (no exploit automation).

Legal reminder: Use everything here only on systems you own or have explicit written permission to test. These resources are for education, training, and authorized assessments only.
